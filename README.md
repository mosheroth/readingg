# השולחן

«אתה חייב לקרוא את זה»: אומרים מה הספר האחרון שקראתם, עונים לאן להמשיך ואם מקור או תרגום, ומקבלים שלושה ספרים. על כל ספר מוצמדת ביקורת טובה וביקורת רעה שנכתבו בסימניה, ואז בוחרים. רק ספר שיש עליו באמת את שני הצדדים נכנס. ביקורת לא מומצאת.

אפשר גם את הסקר הקצר: שש שאלות, ויעל, תום ונדב מניחים על השולחן ספר אחד כל אחד.

הפורמט שואב השראה מערב שבו מתווכחים מה כדאי לקרוא, כמו בתוכנית «אתה חייב לקרוא את זה» בכאן 11. זו לא התוכנית, ואין כאן זיקה לכאן.

ההמלצות רצות אצלכם במכשיר. אין שרת ואין חשבון. בחירה נשמרת במדף מקומי. האפליקציה לא מחלקת את הספרים עצמם. אחרי בחירה יש קישור לעמוד הספר בסימניה, לא לקובץ.

אחרי איסוף ביקורות חדש מרעננים את סל הוויכוח:

```bash
npm run table
```

## אתר סטטי

האתר שמתפרסם הוא קבצים סטטיים בלבד. אין שרת, אין מסד, ואין קריאה ל־API בזמן אמת. הבחירה, הסקר והקטלוג נטענים מהנתונים שנאפו לתוך האתר.

GitHub Actions (`.github/workflows/pages.yml`) בונה עם `BASE_PATH=/readingg/` ודוחף את האתר הבנוי לענף `gh-pages`. הכתובת:

https://mosheroth.github.io/readingg/

ב־Settings → Pages → Build and deployment:

- Source: Deploy from a branch
- Branch: `gh-pages`
- Folder: `/ (root)`

לא `main`. ענף `main` הוא קוד המקור, ו־Pages בנה ממנו עמוד Jekyll ריק.

## הרצה

```bash
npm install

```

## מאגר סימניה

הנתונים נאספים מקומית לשני קבצים. `data/simania-reviews.csv` הוא שורה לכל ביקורת. `data/simania-books.csv` הוא שורה לכל ספר, פעם אחת, גם כשיש עליו כמה ביקורות. `npm run build` ו־`npm run table` הופכים אותם למודולים שהאתר טוען. באתר מוצג תקציר וקישור לסימניה, לא עותק של האתר.

האיסוף לא נכנס ל־`/api/*` של סימניה ולא לעמודים עם `?page=`, כי `robots.txt` שלהם חוסם את זה. בין בקשה לבקשה יש המתנה.

הרצה נוספת ממשיכה מהמספר שבו הקודם עצר:

```bash
npm run crawl -- csv
```

לכל ספר שעוד אין לו עמוד במאגר, האיסוף גם פותח את עמוד הספר ושומר תקציר, דירוג ממוצע, מספר מדרגים, מספר ביקורות בסימניה, צפיות, בעלים, קוראים עכשיו, ISBN, סדרה, עורך ושפה. ספר שכבר נאסף לא נפתח שוב.

אפשר להשלים עמודי ספר לספרים שכבר יושבים בקובץ:

```bash
npm run crawl -- books
```

ברירת המחדל אוספת עד 400 ביקורות בהרצה, או עד שנגמר הזמן. אפשר להגדיל:

```bash
npm run crawl -- csv --limit 2000 --budget 3600000
```

אחרי איסוף, `npm run build` או `npm run table` מכניסים את השורות לאתר. דחיפה ל־`main` מפרסמת את האתר מחדש.
