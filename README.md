# השולחן

סקר קריאה קצר ושלוש המלצות. עונים על שש שאלות, ושלושה קוראים עם טעם שונה — יעל, תום ונדב — מניחים על השולחן ספר אחד כל אחד. בוחרים מביניהם.

הפורמט שואב השראה מערב שבו כמה אנשים מתווכחים מה כדאי לקרוא, כמו בתוכנית «אתה חייב לקרוא את זה» בכאן 11. זו לא התוכנית, ואין כאן זיקה לכאן.

ההמלצות רצות אצלכם במכשיר. אין שרת ואין חשבון. בחירה נשמרת במדף מקומי. האפליקציה לא מחלקת את הספרים עצמם.

## הרצה

```bash
npm install
npm test
npm run dev
```

בניית אתר להתקנה ב־Chrome:

```bash
npm run build
npm run preview
```
